# Ideal Public School Aranda — Official Website

A fully static, production-ready website for **Ideal Public School Aranda** (Aranda, Hasanpura, District Siwan, Bihar - 841236), designed for instant hosting via **GitHub Pages**.

## Features & Highlights
- **Branding & Identity:** Features official school emblem, motto (*"From Darkness to Light"*), and primary brand color `#34261D`.
- **Authentic Data Integration:** Information gathered from official RTE recognition records (Reg. `RTE/SWN/2014-15 0079`), official documents, and current institutional records.
- **CBSE Curriculum:** Complete syllabus pathways from Nursery to Class VIII in English, Hindi, and Urdu.
- **RTE Act 2009 Compliance:** Dedicated 25% free seats reservation guidelines under Section 12(1)(c) for disadvantaged students.
- **Prescribed Books & Prices:** Full list of approved textbooks and maximum retail prices (MRP) for session 2026-27.
- **Verified Faculty Roster:** Certified educators (B.Ed, D.El.Ed, Post-Graduates) and leadership profiles (Director Arshi Kabir, Founder & Secretary Nizamuddin Ahmad).
- **Responsive Architecture:** Built on the Eduhome HTML5 education template with full mobile responsiveness (meanmenu), smooth carousels (Owl Carousel), and lightbox photo gallery (Magnific Popup).

## Deploying to GitHub Pages
1. Push this directory to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Ideal Public School Aranda static website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. Navigate to **Repository Settings -> Pages**.
3. Under **Branch**, select `main` and root (`/`), then click **Save**.
4. The site will be live instantly!
